4.2 Auth & Roles

Auth dùng session token (không phải JWT chuẩn — token là SHA-256 hash lưu DB với expires_at).

RoleTài Khoản DemoQuyền
developerdev / dev@2025Toàn quyền + tab API (CRM key, GA, Google Maps)
owneradmin / aurora@2025Toàn quyền nội dung + user, KHÔNG gán role developer
salessales / sales@2025Workspace sales.html riêng

Flow Đăng Nhập

1. Client: POST /api/auth/login { username, password }
2. Server:
   a. bcrypt.compare(password, user.password_hash)
   b. crypto.randomBytes(32).toString('hex') → token
   c. INSERT auth_sessions (token_hash=SHA256(token), user_id, expires_at)
   d. Trả { token, user: { id, role, name, ... } }
3. Client: sessionStorage.setItem('ah_session', { token, role, ... })
4. Sau đó mọi request: Authorization: Bearer <token>
5. Server: SELECT * FROM auth_sessions WHERE token_hash = SHA256(token)
   AND expires_at > NOW() → đính req.user

5.1 Tích Hợp 3DVista

Tour được build bằng 3DVista Virtual Tour Pro rồi export ra HTML5 (folder data/). Trang VR public nhúng dưới dạng iframe và giao tiếp qua postMessage.

Hướng TinFormat · Mục Đích
Trang → iframe{ type: "goToPanorama", name: "pano-13" } — chuyển cảnh
Trang → iframe{ type: "togglePlay" } — bật/tắt tự xoay
iframe → Trang{ type: "panoramaChanged", id: "..." } — đồng bộ Nav Panel highlight

Module js/vr-bridge.js đóng gói toàn bộ giao tiếp này.

Tại sao chuyển từ Three.js sang 3DVista? Three.js (v1.x) tự render panorama bằng canvas thủ tục — chất lượng hạn chế, không có tile hi-res, hotspot phải tự code lại. 3DVista cung cấp: tile multi-res, hotspot info/scene built-in, gyroscope mobile, video pano, master rotation, tour editor cho marketer chỉnh trực quan.

5.6 URL /<slug> Giới Thiệu Sales

Mỗi sales có slug (vd andy) do Owner đặt khi tạo tài khoản. URL có 2 dạng tương đương:

  • https://<domain>/ — vào trang chung, round-robin gán sales.
  • https://<domain>/andy — vào trang gắn với sales "andy". Project Card hiển thị thông tin liên hệ của andy; mọi lead về thẳng andy.

Server-side: Express route fallback app.get('/:slug', ...) trả về index.html. Trang dùng <base href="/"> nên mọi resource tương đối vẫn load đúng.

Triển Khai

Container (Coolify / Docker)

Project có sẵn Dockerfile + tài liệu COOLIFY.md. Quy trình:

  1. Build image với Node 18+.
  2. Khởi động MySQL container (hoặc dùng MySQL managed bên ngoài).
  3. Cấu hình env: DATABASE_URL, R2_*, PORT, JWT_SECRET, AUTH_TOKEN_TTL_HOURS.
  4. Migrate + seed: chạy migrate-auth.js + seed*.js.
  5. Mount thư mục data/ (3DVista assets) nếu muốn cập nhật tour qua disk thay vì rebuild.

Server Tự Phục Vụ Tĩnh

Express phục vụ cả static files (trang public + admin + data 3DVista) và REST API trên cùng port. Không cần Nginx riêng cho dev.

Production Nên đặt CDN (Cloudflare) trước cho tài nguyên 3DVista trong data/media/ — tải hàng trăm tile/ảnh sẽ rất tốn nếu phục vụ thẳng từ Express.

Giới Hạn Hiện Tại

  • API mở: nhiều endpoint nội dung hiện công khai (không gắn requireAuth). Production cần bọc middleware.
  • Audit log: chưa có log "ai đổi gì lúc nào" per-user. Hiện chỉ có analytics_events.
  • Real-time: trang public chưa có WebSocket/SSE để nhận update khi Owner sửa. Khách phải refresh. (Riêng tính năng "Phát sóng tiến độ" trong Timeline đã có hook real-time qua broadcast.)
  • i18n cho dữ liệu động: tên căn hộ / mô tả tiện ích / testimonial hiện chỉ có VI. Cần thêm translations per-entity nếu muốn dịch.
  • Hiệu năng list BĐS: UI bắt đầu giảm khi vượt ~500 căn cùng lúc. Cần pagination thay vì load all.
  • Audit role assignment: chưa giới hạn IP / 2FA cho tài khoản developer.
  • R2 quota: phụ thuộc plan Cloudflare. Cần monitor.

Thay Đổi v2.0 (so với v1.2)

Breaking Changes

  • VR engine: Three.js → 3DVista iframe. Gỡ js/vr360.js.
  • Storage: data/project.json tĩnh → MySQL backend. Mọi nội dung qua /api/*.
  • Auth: mock sessionStorage → session token thật (bcrypt + SHA-256 hash, TTL 12h, lưu DB).
  • Vai trò: 2 role (Owner/Sales) → 3 role (Developer/Owner/Sales).
  • AI: SpeechRecognition + SpeechSynthesis trình duyệt → Google Gemini Live WebSocket realtime.
  • Media: base64/local → Cloudflare R2 với presigned URL.
